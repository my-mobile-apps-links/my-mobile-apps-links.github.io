隐私政策

Walkie Talkie Pro / Group Talks（iOS com.walkie.takie.pro.walkietalkiepro，Android com.walkie.talkie.pro）
生效日期：2026年10月25日

本文为英文版隐私政策的翻译。如有任何不一致，以英文版为准。

Walkie Talkie Pro 可将您的手机变成一键通（push-to-talk）对讲机：您加入一个带编号的频道，即可与该频道中的所有人通话。 本政策说明本应用会处理哪些信息、处理的原因以及您拥有的选择。简而言之：本应用没有账户，从不要求您提供姓名、电子邮件、 电话号码、通讯录或位置。您的语音实时传输，绝不会被录制或存储。本应用免费并展示 Google AdMob 广告；可选的 Pro 订阅可去除广告。

1. 您的语音

  • 本应用仅在您连接到频道时使用麦克风（因此您的手机会显示麦克风指示）。其他人只有在您按住通话按钮时 才能听到您的声音；其余时间您处于静音状态，到达我们服务器的任何音频都会被丢弃，不会转发。连接期间，本应用会在后台继续运行， 以便您能继续听到其他人。
  • 您的语音通过加密连接（WebRTC、DTLS-SRTP）发送到我们的音频服务器，服务器将其混音后实时播放给同一频道中的其他人。 如果无法建立直接连接，加密音频可能会经过由 Metered 运营的中继（relay）服务器。
  • 音频不会被录制、存储、转写或分析，无论是我们还是任何其他人。
  • 频道是共享的。任何加入相同频道号的人都能听到您说的话。如需限制收听者，请使用 PIN 码将频道设为私密， 并且切勿在频道中谈论敏感内容。

2. 我们在服务器上存储的数据

我们的服务器（walkie-talkie.api.writai.app）仅存储运行频道和通知所需的内容：

  • 设备记录：由 Firebase 生成的推送通知令牌（一个随机 ID，与您的身份无关）、您的设备型号（例如 "iPhone11,8"）、您所在的频道、您是否已连接，以及当有人在您的频道中讲话时是否希望收到通知。
  • 私密频道：频道号、您设置的 PIN 码，以及其设置时间和到期时间。私密频道到期或被重置时，PIN 码会被删除。
  • 反馈：如果您在应用内为本应用评分或撰写反馈，我们会存储评分和您输入的文字（不含任何标识符）。 请不要在其中包含个人信息。
  • 购买：当您购买或恢复 Pro 时，我们会记录价格以及这是新购买还是恢复购买，不含任何标识符。
  • 邀请链接：当邀请链接（walkietalkiepro.app/join/…）被打开时，我们会记录一次打开， 并附带频道号和从浏览器获取的平台（Android、iOS 或其他）。我们不存储您的 IP 地址或完整的浏览器信息；邀请链接中的 PIN 码位于 # 之后，因此绝不会发送到我们的服务器。

发往我们服务器的请求受 Firebase App Check 保护，使服务器能够确认请求来自正版应用。

3. 仅保存在您设备上的数据

您的设置、最近和收藏的频道、您加入过的频道的 PIN 码、新手引导和教程进度，以及 Pro 状态的缓存副本，都存储在应用的私有存储中。 在 Android 上，如果您通过邀请链接安装了本应用，应用会读取一次 Google Play 安装来源（install referrer）以打开该频道。

4. 通知（Firebase Cloud Messaging）

如果您允许通知，本应用会使用 Firebase Cloud Messaging 在有人开始在您的频道中讲话或您的私密频道即将到期时通知您。您可以在应用中关闭频道通知，或在设备设置中拒绝通知权限。

5. 广告（Google AdMob）

免费用户会看到由 Google AdMob 提供的横幅广告、激励广告以及偶尔出现的全屏广告。为投放、衡量和限制广告以及防止欺诈，Google 可能会收集您的 IP 地址（用于大致位置）、设备和应用信息、广告互动，以及在允许的情况下您设备的广告标识符。

  • iPhone 和 iPad：本应用不请求跟踪权限，因此您的广告标识符（IDFA）不会与广告商共享。
  • Android：您可以在设置 → Google → 广告（或设置 → 隐私 → 广告）中重置或删除您的广告 ID。
  • 欧洲经济区、英国和瑞士：在投放个性化广告之前，本应用会显示 Google 的同意请求。

Pro 用户不再看到广告，本应用也不再请求广告。

6. 使用统计和崩溃报告（Firebase）

  • Firebase Analytics 会接收应用事件（例如连接到频道、使用通话按钮、创建私密频道、展示广告、查看 Pro 页面、完成或恢复购买），以及 Firebase 自动收集的信息：随机的应用实例 ID、设备型号、操作系统版本、应用版本、语言、大致国家/地区和会话信息。这些数据绝不包含您的语音、 姓名、电子邮件或精确位置，Google 最多保留 14 个月。
  • Firebase Crashlytics 会接收崩溃报告（堆栈跟踪、设备型号、操作系统和应用版本、随机安装 ID），以便我们修复错误。
  • Firebase Remote Config 使用随机安装 ID 以及基本的设备和应用信息下载配置值（例如广告可以出现的频率）。

7. 购买和订阅

Pro 是一项可选的自动续订订阅（在某些版本中为一次性购买），通过 Apple App Store 或 Google Play 销售。 付款完全由 Apple 或 Google 处理；本应用永远不会看到您的付款信息。应用仅接收购买状态，用于解锁 Pro 并在您的其他设备上恢复。 您可以随时在 App Store 或 Google Play 账户设置中取消订阅。

8. 权限

  • 麦克风：在您按住通话按钮时将您的语音发送到频道（通话所必需）。
  • 通知：提醒您频道中的动态（可选）。
  • 后台音频 / 前台服务、电池优化（Android）：让您在应用处于后台时保持连接并能听到其他人。
  • 网络和网络状态：用于连接频道、广告、分析和配置服务。

本应用不使用您的相机、照片、通讯录或位置。

9. 共享

我们不出售您的数据。数据仅与上述服务提供商共享（Google Firebase 和 AdMob、用于音频中继的 Metered，以及用于购买和应用评价的 Apple 或 Google），并且始终通过加密连接传输。您的语音会被您频道中的其他人听到。

10. 数据保留和删除

  • 在您使用本应用期间，您的设备记录会被保留；断开连接会将您标记为离线，卸载应用会使其通知令牌失效。
  • 私密频道的 PIN 码会在频道到期或被重置时删除。
  • 卸载应用会删除您设备上存储的所有内容。
  • 由于我们不收集您的身份信息，我们无法按姓名或电子邮件查找数据，但您可以就任何请求联系我们（见下文），我们会为您提供帮助。

11. 儿童

本应用不面向 13 岁以下的儿童，也不会在知情的情况下收集儿童的个人信息。由于频道与其他人共享，儿童只应在家长监护下使用本应用。

12. 变更

如果本政策发生变更，更新后的版本将连同新的生效日期发布在本页面上。
